# Living Japan

用于小说写作的 SillyTavern 扩展。以 Living Japan v3.6 的功能与内置正文为基准，接入已确认的横版、竖版、手机界面。

当前为 **0.1.0 迁移候选版**。独立预览与自动检查不代表已经完成真实酒馆、手机和模型验收。

## 安装

① 在酒馆的「扩展」中选择「安装扩展」，粘贴仓库地址：

https://github.com/yyxz223-stack/Living-Japan

② 安装完成后刷新酒馆网页，点右侧的「LJ」打开。默认显示首都圈；全国地图按地区读取，第一次切换地区需要等待加载。

③ 启用前先在旧 v3.6 面板导出个人修改稿，再停用旧 Living Japan 脚本，避免两套同时接管同一个宏。新扩展「设置 → 备份与说明」可预览导入内容并确认恢复。原有提示词中的 `{{livingjapan}}` 继续使用。

无需下载旧脚本 JSON，无需解压，无需安装 Python 或 osmium。酒馆必须允许安装第三方扩展。

## 内容与操作

- 保留 879 个既有正文包、1,334 个原编辑槽及旧注入规则。正文与用户修改稿不参与地点搜索。
- 以八大区为顶层的地区树、地图地点与服装门店保留各自身份和来源。图上有地点不代表已有正文；可自行新增任意数量的正文空位。
- 地图有「示意、地图、精细、超精细」四种模式。地图位置、选中对象、追加名称和正文编辑是独立操作。
- 地点名字保持固定偏移，整段名字可以点击；同一缩放级别平移不再按屏幕格重排点位。公园沿实际地块填色，铁路与行政边界使用核验过的 PBF 路径，按视野和缩放分层读取。
- 双击地点名称只追加到聊天输入框；路线「出发」追加交通备注，都不自动发送。旧交通估算范围以已收录数据为准。
- 本级正文和整支开关分开；暂停整支保留下级选择。外部地域和内部场所保留各自控制关系。
- 用户稿优先于内置原文；同一正文槽从不同入口打开时共用保存内容。同名地点或不同正文槽不会按名称合并。

## 更新与个人数据

在酒馆扩展管理中更新，或用「设置 → 备份与说明」里的更新入口。扩展更新后刷新网页。

个人设置、正文修改稿及自建空位保存在酒馆当前用户的文件区，文件名为 **living-japan-user-data.json**，不写进扩展目录。只有写入并读回成功，界面才提示保存完成。更新内置原文会保留个人稿，并显示原文版本变化。

换设备前导出完整备份；在另一设备导入时先查看覆盖统计。不要同时在两个设备修改同一份稿件。

## 来源与范围

全国地图地点来自原有 v3.0.0 分区资料；行政层级使用官方代码及已核映射。新增铁路与完整行政边界来自 2026-10-27 日本 PBF 的定向提取；缺少完整形状的对象不补直线。地图展示记录可能跨分区出现，不能把展示记录总数当作去重地点总数。服装门店为 2026-09-07 资料快照。

PBF 中筛出的地点仍须与既有库核对，未经确认的保留为维护候选，不自动合并或叠加到正式地图。

2.5 GB 的日本 PBF 原始文件没有随扩展发布。原始数据处理只在维护阶段进行，浏览器按分包读取。来源与许可分别见 [数据来源](data/national/sources.json)、[许可文件](data/national/licenses/)及 [数据清单](data/national/manifest.json)。

发生问题时，先保留完整用户备份，再复制「检查」页完整诊断结果。安装、更新和恢复见 [安装与恢复](docs/安装与恢复.md)。
