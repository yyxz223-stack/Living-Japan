# 安装、更新与恢复

## 首次安装

1. 旧 Living Japan v3.6 用户先导出个人修改稿，保留下载的 JSON；旧脚本本身也保留。
2. 酒馆「扩展 → 安装扩展」粘贴 `https://github.com/yyxz223-stack/Living-Japan`。不下载旧助手脚本，不把源码 ZIP 当世界书导入。
3. 安装后刷新酒馆网页，停用旧 Living Japan 脚本，再打开右侧 LJ 入口。
4. 有旧稿时进入「设置 → 备份与说明」，选择备份文件，先看导入统计，再确认应用。没有旧稿可直接使用。
5. 原有提示词保留 `{{livingjapan}}` 宏。仅打开地图不会自动修改提示词或发送聊天。

## 日常保存

保存正文后等待「已保存并读回」。如果显示失败，编辑框保留未保存内容；先复制或保留当前稿件再排查，不要直接刷新。

保存位置是酒馆当前用户文件区的 `living-japan-user-data.json`。这是服务器文件；只在浏览器中清理缓存不会备份它。不要手动移动此文件到扩展目录。

新增空位只增加用户记录；空白内容不会借用别的地点正文。恢复内置原文只移除当前一份修改稿。

## 更新

更新前可导出完整备份。使用酒馆扩展管理的更新按钮，或本扩展设置页提供的更新操作。更新完成后刷新酒馆网页；通常不需要重启电脑。

代码与内置数据属于扩展发布文件；个人内容属于酒馆用户文件区。内置原文发生变化时，已有个人修改稿继续优先生效，并提示所基于原文已变化。

从 ZIP 手动放入的扩展可能无法在线更新。此时保留个人备份，改用仓库地址在扩展管理中安装。不要把提示“检查失败”当成“没有更新”。

## 恢复

完整备份包括正文、设置、自建空位与界面偏好。导入先预览新增、覆盖、无法对应与原文变化数量，确认后才保存。无法对应的旧稿会保留，不能自动按名称猜配。

回退旧脚本时先停用本扩展，再启用原 v3.6。旧脚本只支持它原有的正文槽，不能承接新扩展新增的全部空位；保留新扩展完整备份以便继续使用。

## 出错时提供什么

- 页面可打开：复制「检查」页完整诊断结果，并说明出错的地点、操作和是否刚更新。
- 保存失败：记下界面错误文字，保留未保存稿件，不要先卸载扩展。
- 无法打开：提供酒馆启动窗口中带 `[Living Japan]` 的错误，以及浏览器显示的错误文字。

开发用独立预览的用户文件位于工程 `.preview-user/`，与真实酒馆分开。隔离预览成功不代表真实酒馆、手机或模型验收已完成。
