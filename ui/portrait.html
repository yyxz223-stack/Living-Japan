竖版代表性测试链

  
直接按顺序点击即可，重点查看正文、上下级和地图之间的往返。

  
    
    
  1. 平级地点独立选定：点击地图相关地点名称「恩赐上野动物园」，它会替换大标题成为当前目标，可单独搜索和设起终点；它与上野站同属台东区，不是父子关系。
    2. 
    
  2. 地图内查看与修改：单击切换地点 · 双击地点大标题追加；右侧「追加」只追加名称。要看正文，请先让地点成为大标题，再点「查看详情」。正文以全宽侧层覆盖地图；点击「编辑修改稿」修改并保存，内置原文只读，修改稿与地区页共用，需连续点击两次「恢复原版」才会还原。
    3. 
    
  3. 地区最深层：顶部「地区」→「行政结构」→「全国」→「东京都」→「台东区」→「上野站」。具名地点只显示同层相关地点；行政路径和抽屉可返回上级。
    4. 
    
  4. 全地图正文：左上角线性展开图标 → 无边全地图；同样单击切换地点 · 双击地点大标题追加，并可使用「追加」或「查看详情」。关闭正文后仍留在全地图，并保留路线。普通地图与全地图的路线框内都可「清空起终点」，底部可切换四种出行方式。
    5. 
    
  5. 资料与只看更改：顶部「资料」分别进入四个大项，沿分组进入最末级正文；保存修改稿后勾选「只看更改」。诊断的当前聊天预览优先使用修改稿，上一轮实际记录不变。
    6. 
    
  6. 其他大区块：「诊断」的结果可进入对应资料或地点；「设置」可进入读取设置、常用地点与备份说明；各页均可切回地图。
    7. 
  

  
切回横版：点击右上角「横」，或进入「设置 → 常用设置 → 横版」。普通地图与全地图会分别对应横版的普通地图与全地图；互跳会打开另一个文件，不保留未保存的修改。
